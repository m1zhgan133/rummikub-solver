# Rummikub Solver

Проверка того, можно ли разложить **все** фишки на столе в Rummikub на корректные наборы без остатка, и поиск самой раскладки.

- **Группа** — 3–4 фишки одного числа разных цветов.
- **Ряд** — 3+ фишки одного цвета с подряд идущими числами (без перехода 13 → 1).
- **Джокер** — заменяет любую фишку.

## Алгоритм

Динамическое программирование по числам 1..13 (den Hertog & Hulshof, 2006). Состояние: число `v`, для каждого из 4 цветов количество открытых рядов длины 1, 2 и ≥3, и оставшиеся джокеры. Состояния мемоизируются, раскладка восстанавливается повторным проходом по сохранённым решениям. Подробности — в докстринге `rummikub_solver.py`.

## Использование

Python 3.8+, без внешних зависимостей.

```python
from rummikub_solver import solve_table

# фишка = (число, цвет), цвета: 'о' — оранжевый, 'ч' — чёрный, 'к' — красный, 'с' — синий; джокер = (0, 0)
tiles = [(1, 'о'), (2, 'о'), (3, 'о'), (7, 'к'), (7, 'с'), (7, 'ч')]
ok, rows = solve_table(tiles)
print(ok, rows)
```

Пример с большим столом: `python3 test.py`.

## Веб-интерфейс

Откройте `index.html` в браузере: отмечаете фишки на столе, страница показывает, разрешим ли стол, и саму раскладку. Сервер не нужен.
